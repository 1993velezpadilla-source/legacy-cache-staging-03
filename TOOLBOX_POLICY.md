# Felix / Volnox Full Toolbox Policy

Felix / Volnox may read and reuse the technical toolbox from the ZOMBIESSSSSSS PORTABLE project while writing all new collaborator work here.

## Reusable capabilities
- 3D models, GLB/FBX/OBJ assets and model-generation workflows
- character bases, rigs, skeletons, armatures and measurements
- animation, retargeting, baking and runtime conversion
- Blender modeling, cleanup, UV/materials, rigging, animation, rendering and export
- Hayuya 3D / Hunyuan3D-style image-to-3D generation
- VFX/effects/particles/shaders/lighting
- textures/materials/masks/reference-image workflows
- audio/ambient/sound-effect pipelines
- maps, environments and scene composition
- exporters, build helpers, CI/workflows, runtime/Android validation and optimization
- scripts, research, documentation and future project tools unless explicitly restricted

## Cross-repo reuse rule
Owner/project files in the two reference repositories may be read, invoked where execution permits, or copied into this repo as derived tools/assets where licensing/provenance allows.

If an owner tool needs customization, copy or wrap it HERE. Do not mutate the owner source just to make Felix's version.

## Secrets
Never print, copy, or commit credentials/API keys. Existing project secrets may only be used through already-authorized workflows/runtimes that keep them hidden.

## External assets
Record source/provenance and license/usage status. Do not commit material the project is not permitted to redistribute.

## Runtime truth
Repository access != execution access. If a runtime is unavailable, prepare the job here and mark it `PREPARED_NOT_EXECUTED`.
